Seed checker

Check any Jammmy Games bet yourself. Paste the revealed server seed, your client seed and the nonce. This page works it out in your browser from scratch, and shows every step so you can repeat it with any SHA-256 / HMAC-SHA256 tool.

How it works

1. Before you play, you're shown SHA-256(server seed). The seed itself stays secret, so the result is locked in but nobody can see it yet.
2. Each bet's random numbers come from HMAC-SHA256(key = server seed, message = "client seed:nonce:round"), round = 0, 1, 2… Each 32-byte result gives 8 numbers between 0 and 1 (4 bytes each: b0/256 + b1/256² + b2/256³ + b3/256⁴).
3. Mines: those numbers shuffle the 25 tiles (Fisher–Yates); the first tiles of the shuffle are the mines. Plinko: one number per row, under 0.5 = left, otherwise right. HiLo: card = floor(number × 52), one number per guess. Blackjack: the 6-deck shoe (312 cards) is shuffled with whole 32-bit numbers from the same HMAC.
4. When you rotate your seed pair, the old server seed is revealed. Anyone can hash it and check it matches what you were shown, then recompute every bet made with it.
HiLo note: the first card on the table before you bet is just a random starting card (you can skip it for free); every card after you bet comes from the seeds.
